## r8 Grok 장애 점검

- 기존 작업 기록에서 `프롬프트 입력값 불일치`, `실행 직전 대상이 변경되었습니다`, `2:3` 옵션 탐지 실패를 확인했습니다. 완료된 다운로드 기록은 없었습니다.
- 실제 HONMOON 프로필의 Grok 저장 이미지 상세 화면을 조사했습니다. 결과가 편집기에 자동 첨부되며, 이미지/비디오 모드와 별도의 결과 다운로드 버튼이 있습니다. 480p 설정을 확인했습니다.
- 로컬 Chromium에서 `agent-browser fill`이 이미 내용이 있는 contenteditable에 글을 덧붙이는 증상을 재현했습니다. 포커스를 확인한 편집기만 비우고 입력·검증하도록 수정했습니다. ProseMirror 빈 문단과 개행도 구분합니다.
- 결과 상세 화면, 편집기/메뉴 범위, `aria-pressed` 오디오, 옵션 공백 변형을 지원합니다. 동일 DOM 노드가 레이아웃 이동한 경우 최신 selector로 실행하며, 실제 노드 교체는 여전히 중단합니다.
- 이미지→영상 2단계와 기존 이미지 ID→영상 경로를 추가했습니다. 단계별 승인/제출 기록을 유지하며 이미지 포스터를 영상 완료로 오인하지 않습니다.
- **실사이트 기존 이미지 다운로드 1회 확인:** JPEG, 270,750바이트, Electron completed 이벤트 및 파일 존재 확인. 새 생성/비용 발생 없음. Grok의 주소는 원본 URL이 아닌 `blob:https://grok.com/...`였습니다. 이 때문에 기존 결과 주소 대조가 실패할 수 있어, 탭·결과 ID·파일명·단발 다운로드 이벤트에 결합한 검증을 추가했습니다.
