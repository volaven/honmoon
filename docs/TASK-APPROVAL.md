# 작업 전체 승인 · 시험판 r6

작업 입력 아래 **작업 전체 승인 후 시작**을 누르면 시작 전에 범위를 검토할 수 있습니다. 이미 실행 중이면 **이 작업 전체 승인**을 사용합니다. 현재 승인 대기 창에도 같은 버튼이 있습니다. 시작 전 검토 화면은 2분 만료가 없으며, 최종 확인 버튼을 눌러야 작업이 시작됩니다.

- 현재 탭·사이트·작업 지시·선택한 파일에 한해 입력, 선택, 클릭, 파일 전송, 조회, 복구 관측을 한 번에 허용합니다. 에이전트가 작업 지시를 해석해 구체적인 입력과 동작을 정합니다.
- 생성 제출 한도는 기본 1회이며 1~10회로 정할 수 있습니다. 생성 옵션은 작업 지시를 따르고 미지정 값은 사이트 설정을 사용합니다. Grok Lite 영상 작업에는 `480p`를 명시하세요.
- 비용을 확인하지 못해도 진행하려면 검토 화면의 해당 항목을 직접 선택합니다. 선택하지 않으면 비용 불명확 단계에서 별도 확인을 요청합니다. 금액 상한을 강제하는 기능은 아닙니다.
- 탭 전환·중지·임대 만료·종료 시 승인은 해제됩니다. 새 작업이나 다음 실행에 승인이 승계되지 않습니다. 이후 추가된 파일도 승인에 포함되지 않습니다.
- 대상과 입력의 실행 직전 검증, 승인 후 설정 변화 검사, 중복 제출 방지, 다운로드 검증은 유지됩니다. 원격 생성이 접수된 뒤에는 중지하더라도 사이트 생성이 계속될 수 있습니다.
- 검증된 생성 또는 완료 조건이 확인된 작업은 추가 결과 승인 없이 끝납니다. 근거가 부족하면 성공으로 표시하지 않습니다.
- 로그인, 카메라·마이크 등의 웹 권한은 작업 전체 승인에 포함하지 않습니다. 외부 MCP와 모델에는 승인 도구를 공개하지 않습니다.

## 로그인 유지

모든 생성 시험판은 `%APPDATA%\HONMOON-Media-Preview`와 `persist:honmoon-default` 파티션을 계속 사용합니다. r2에서 r6로 실행 파일 위치가 달라져도 같은 프로필을 엽니다. 쿠키·Codex 인증을 복사하거나 초기화하지 않습니다. 정상 종료 시 쿠키와 저장소를 디스크에 반영합니다. 사이트 자체의 세션 만료·로그아웃은 별개입니다.

작업 승인은 메모리에만 유지되므로 쿠키와 함께 다음 실행으로 넘어가지 않습니다.
