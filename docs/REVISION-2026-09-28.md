# 2026-09-28 수정 및 검증

## 브라우저 GUI

Windows 기본 제목 표시줄을 숨기고 탭 줄 안에 최소화·최대화·닫기를 배치했습니다. 빈 탭 줄은 창 드래그 영역이며 탭/버튼은 클릭 영역입니다. 큰 HONMOON 로고, 왼쪽 장식 사이드바, 슬로건과 중복 상태 띠를 제거했습니다. 탭·주소·탐색·다운로드·기록·설정과 접을 수 있는 에이전트 패널을 남겼습니다. 새 탭은 간단한 검색 화면이고 로컬 테스트 사이트는 설정에서 열 수 있습니다.

## 실행파일 처리

- agent-browser Windows 실행파일을 패키지의 resources 바로 아래에 명시적으로 복사하고 해당 절대 경로로 실행합니다.
- Codex 탐색은 PATH, 사용자가 지정한 경로, Codex 데스크톱 설치 경로를 검사하고 실제 --version 실행에 성공한 바이너리만 채택합니다. 재연결 때 다시 탐색합니다.
- 설정에 연결 재시도와 codex.exe 위치 지정 기능을 추가했습니다. 이전 프로세스의 종료/응답이 새 연결에 섞이지 않도록 프로세스 식별 검사를 적용했습니다.
- PATH가 비어 있는 환경에서 실제 Codex app-server 초기화와 모델 7개 조회, agent-browser 버전 확인을 통과했습니다.
- 사용자가 보신 “바이너리 실패”의 전체 오류 문구는 제공되지 않았습니다. 원래 오류와 동일한 원인이라고 단정하지 않으며, 위 실행 경로 보완과 배포본 재검증을 구분합니다.

## 토큰을 전달하는 경로

모델은 기능 구현 소스코드를 읽지 않습니다. Codex에 제공하는 함수 스키마, 기능의 짧은 ID·이름·행동·입력 규격과 변경분을 읽습니다. agent-browser의 접근성 스냅샷은 로컬 어댑터가 처리합니다. 실행에 쓰는 전체 계약·요소·탭·origin·승인·파일 검사는 로컬에 남습니다.

첫 목록 이후 같은 작업에서는 changed/removed를 전달하고 목록이 같으면 unchanged를 전달합니다. unchanged는 기능 목록만 같다는 뜻입니다. 본문 변화나 작업 성공을 뜻하지 않습니다. 본문이 필요한 작업은 승인된 page.read, 실패 조사는 승인된 단계적 관측을 이용하므로 추가 토큰이 발생합니다.

## 측정 해석

evidence/token-comparison.json과 TOKEN-COMPARISON.md에 실제 내장 Chromium에서 수집한 문자열을 tiktoken 0.12.0 / o200k_base로 센 결과를 기록합니다. 이는 지정 인코딩의 문자열 토큰 수이며 실제 Codex 청구 사용량이나 작업 완료율 측정이 아닙니다. 작은 페이지나 이미 압축된 접근성 목록과 비교하면 첫 목록이 더 클 수 있습니다. Flow/Grok 각 10개 실제 작업의 40% 절감 목표는 아직 입증하지 않았습니다.

## 내장 Chromium 입력 회귀 검사

다른 창에 가려진 페이지의 display surface가 사라져 클릭 완료 응답이 실제 DOM 이벤트로 이어지지 않는 현상을 재현했습니다. Chromium의 native window occlusion/backgrounding을 비활성화하고 최소화된 창은 실행 전에 복원합니다. 표시에 따른 소비 전력이 증가할 수 있는 선택이며, 보안 격리 옵션을 끄는 변경은 아닙니다. 제어 보호막은 자식 뷰를 정렬한 뒤 가시성을 적용합니다.

이 변경 이후 개발판에서 실제 클릭을 포함한 탭 생성·선택·닫기 20회와 입력·승인·업로드·다운로드·취소·인증 차단 등 통합 검사 20개를 통과했습니다. 조사 중 시도한 Electron 직접 마우스 입력 대체 경로는 제거했으며, 최종 클릭은 고정 버전 agent-browser를 통해 실행합니다. 앞선 실패 실행은 통과로 집계하지 않았습니다.

참고: [Chromium native window occlusion](https://chromium.googlesource.com/chromium/src/+/show/136.0.7103.59/docs/windows_native_window_occlusion_tracking.md), [Electron custom title bar](https://www.electronjs.org/docs/latest/tutorial/custom-title-bar).
