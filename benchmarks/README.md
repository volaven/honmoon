# Flow / Grok paired pilot

아직 실계정 실험은 수행하지 않았습니다. 두 사이트 각각 동일한 10개 작업을 baseline과 HONMOON으로 한 번씩 실행하고 `template.json` 형식으로 기록합니다. 동일 모델, 계정, 입력 파일, 결과 판정 기준을 유지하며 순서를 교차합니다. 생성 비용과 외부 전송은 사용자가 매번 승인해야 합니다.

baseline은 동일한 전용 Chromium에서 매 단계 전체 스냅샷을 제공하는 통제군입니다. 별도 Chrome이나 기존 Chrome 프로필을 사용하지 않습니다. HONMOON 작업 기록의 usage.inputTokens는 실제 app-server 사용량 알림에서 작업 시작 전 누적치를 뺀 값이며, 캐시 입력은 별도 필드입니다. 토큰 알림이 없으면 누락으로 남기고 문자 수로 대체하지 않습니다.

`node benchmarks/evaluate.mjs results.json`으로 사이트별 입력 토큰 중앙값 감소율, 완료율 차이, 오인 제어·승인 누락을 계산합니다. 20개 짝이 모두 없으면 합격을 반환하지 않습니다. 잘못된 탭, 승인 우회, 중복 생성은 각 작업에 따로 기록합니다. 실제 생성 실패를 로컬 테스트 결과로 대체하지 않습니다.
